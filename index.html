Projects

Machine Learning

Linear Regression from Scratch

Gradient descent built by hand with only NumPy and no sklearn. Derives and implements MSE loss with vectorized partial derivatives. Includes a loss curve, learning rate comparisons, and a raw vs vectorized speed benchmark.

Python · NumPy · Calculus · Matplotlib

k-Nearest Neighbors Image Classifier from Scratch

Implemented and evaluated a k-NN classifier in Python and NumPy to classify clothing items from the Fashion-MNIST dataset. Includes vectorized Euclidean and Manhattan distance calculations, custom prediction and tie-breaking logic, confusion matrices, accuracy and macro-F1 evaluation, and 5-fold cross-validation for hyperparameter tuning. Compared different values of k and distance metrics to measure their effect on classification performance.

Python · NumPy · Fashion-MNIST · Cross-validation

Language Modelling

Makemore: Character-Level Language Model

Built a bigram language model from scratch that learns to generate human-sounding names. Implemented both a statistical approach using count matrices and probability distributions, and a neural network trained on the same problem using gradient descent and the negative log likelihood loss.

PyTorch · Language Modelling · Bigrams · NLL Loss
